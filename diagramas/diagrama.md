# Diagramas — Gestión de Medicamentos Hogar Gerontológico

## Creación

Con la ayuda de IA agéntica generamos el código Mermaid de los diversos diagramas de arquitectura (C4), e incluso el del proceso de PRs.

## Herramienta de visualización

La representación visual de los diagramas proviene de <https://diagrammingai.com/> (de pago). Es la herramienta más flexible en costos y generó los diagramas prácticamente sin retrabajo.

## Proceso

1. **Código Mermaid:** creación del código Mermaid con IA agéntica.
2. **Generación:** se copia de este repositorio el código de un diagrama Mermaid y la herramienta genera el gráfico (PNG).
3. **Exportación:** se descarga el diagrama en formato PNG para incluirlo en el proyecto.

**Nota:** este es un proceso manual y para fines de entrega de este proyecto formativo. Los diagramas se renderizaran de forma nativa en github.
